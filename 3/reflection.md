# Рефлексия
Минусом являвется то что я не сделал реализацию transfer_message через dependency injection. Это уменьшает гибкость решения. Также минуосом может быть отдельный набор классов для обработки команды - для каждого робота прийдется писать свой набор, т.е. дублировать примерно однообразный код. Плюсом является атомарность каждой функции и скрытие реализации от пользователя, некая неформальная спецификация через постусловия и предусловия с возможностью управлять набором дейсвтий, которые можно сдлеать над роботом, например при разработке набора разных роботов.
